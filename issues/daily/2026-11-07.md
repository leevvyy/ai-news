### L1 · Report a monitor's recall at a fixed false-accusation rate, with an interval

`LLM / agent evaluation` · now 2.5 → target 4.5 · priority 2.00 · ~15 min

**Why today.** The Project EVE item reports monitor agents catching 30-40% of saboteurs at 5% false accusations, a recall-at-fixed-FPR number. ([Anthropic's Project EVE: Claude agents trade in EVE Online and run fleets in EVE Frontier, with sabotage tests](https://www.anthropic.com/research/project-eve-claude-plays-mmorpgs))

A monitor outputs a score; a single accuracy figure hides the trade-off between catching saboteurs and accusing honest agents. Fix the false-positive rate first (here 5%), set the threshold at the matching quantile of honest-agent scores, then report recall (true-positive rate) at that threshold. With only tens of positives the estimate is noisy, so bootstrap the saboteur scores to get an interval. It breaks when honest scores are not representative of deployment, or when saboteurs adapt to the threshold. The numbers below are illustrative, not from the Anthropic study.

$$
\mathrm{thr}=Q_{1-\alpha}(s_{\text{honest}}),\quad \mathrm{recall}=\frac{1}{n}\sum_i \mathbf{1}[s_i>\mathrm{thr}]
$$

```python
import random
random.seed(0)
# Illustrative: a monitor scores agents; saboteurs score higher on average.
n_s, n_h = 40, 400
sab = [random.gauss(1.5, 1.0) for _ in range(n_s)]
hon = [random.gauss(0.0, 1.0) for _ in range(n_h)]
# threshold = (1 - FPR) quantile of honest scores
fpr = 0.05
thr = sorted(hon)[int((1 - fpr) * n_h)]
tp = sum(s > thr for s in sab)
recall = tp / n_s
def boot():
    r = [random.choice(sab) for _ in range(n_s)]
    return sum(s > thr for s in r) / n_s
bs = sorted(boot() for _ in range(2000))
print(f"threshold={thr:.2f} recall@5%FPR={recall:.2f} 95% CI=({bs[50]:.2f},{bs[1949]:.2f})")
```
