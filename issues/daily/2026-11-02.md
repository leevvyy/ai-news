### L1 · Put an error bar on a success rate before comparing agents

`LLM / agent evaluation` · now 2.5 → target 4.5 · priority 2.00 · ~10 min

**Why today.** AgiBot's own figure of task success rising from 28.6% to 85.7% is a before/after comparison of two rates, and the item gives no trial counts. ([AgiBot puts six Genie G2 robots on a 24-hour convenience-store shift livestream from Nov 2](https://tech.ifeng.com/c/8xYkg1r1tJG))

A success rate k/n is an estimate of a true rate p, and its uncertainty depends on n far more than on k. The Wilson score interval inverts the normal approximation to a binomial test and, unlike the naive p ± z·sqrt(p(1-p)/n), stays inside [0,1] and behaves at small n or extreme p. With few trials the intervals for two rates can overlap heavily, so a before/after jump is weak evidence; the same percentages from ten times as many trials are far tighter. It still assumes independent trials of equal difficulty, which an agent run in one store over several days violates. The numbers below are illustrative (2/7 and 6/7 happen to give the quoted percentages), not AgiBot's actual counts.

$$
\hat p = k/n,\quad \text{CI} = \frac{\hat p + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat p(1-\hat p)}{n} + \frac{z^2}{4n^2}}}{1 + z^2/n}
$$

```python
from math import sqrt
def wilson(k, n, z=1.96):
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return c - h, c + h
for k, n in [(2, 7), (6, 7), (60, 70)]:
    lo, hi = wilson(k, n)
    print(f"{k}/{n} = {k/n:.1%}  95% CI [{lo:.1%}, {hi:.1%}]")
```
