### L1 · Drawdown arithmetic: why an 11% drop needs a 12.4% gain to undo

`Domain AI (finance, health)` · now 3.5 → target 4.5 · priority 0.70 · ~10 min

**Why today.** The item reports the semiconductor index falling about 11% in one session, with closing figures varying by outlet. ([AI chip rout: Nvidia falls about 9%, semiconductor index roughly 11% lower, S&P 500 and Nasdaq sharply down](https://finance.yahoo.com/markets/live/stock-market-today-thursday-november-5-dow-sp-500-nasdaq-plunge-chip-stocks-melt-down-193726491.html))

Percentage returns compound multiplicatively, so a loss of d needs a gain of 1/(1+d)-1 to return to the starting level, which is always larger than |d|. Log returns, ln(1+r), add across days, which makes them convenient for aggregating and for statistics, but they differ noticeably from simple returns for large moves like this one. Quoted figures also depend on whether an outlet uses a close, an intraday low or a snapshot, so compare like with like before drawing conclusions. The numbers below are illustrative, not market data.

$$
g_{rec} = \frac{1}{1+d} - 1, \qquad r_{log} = \ln(1+r)
$$

```python
import math
# Illustrative drawdown arithmetic (the -11% is the figure in the item; the rest is toy).
drop = -0.11
need = 1 / (1 + drop) - 1          # gain needed to get back to the old level
logret = math.log(1 + drop)        # log return, additive across days
print(f"simple {drop:.1%} -> recovery needs {need:.1%}; log return {logret:.4f}")
# toy: a -11% day followed by +4%, +3% days
level = 1.0
for r in (-0.11, 0.04, 0.03):
    level *= 1 + r
print(f"after -11%, +4%, +3%: level {level:.3f} ({level-1:+.1%})")
```
