### L1 · Measure whether a yes/no judge's probabilities are calibrated: Brier score and ECE

`LLM / agent evaluation` · now 2.5 → target 4.5 · priority 2.00 · ~12 min

**Why today.** Google pitches Gemini Decision 1 as returning fast, calibrated judgments for classification and rubric scoring, and calibration is a property you can measure rather than take on trust. ([Google launches Gemini Decisions API with Gemini Decision 1 for fast, calibrated multimodal judgments](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/))

A judge is calibrated if, among all items it scores at probability q, a fraction q are actually positive. The Brier score, the mean of (q - y)^2, is a proper scoring rule: it is minimised in expectation by reporting the true probability, and it mixes calibration with sharpness (how far from 0.5 the forecasts sit). Expected calibration error bins forecasts by q and averages |confidence - accuracy| weighted by bin size, isolating miscalibration. The simulation shows that both overconfident and underconfident judges raise the ECE about twelvefold while the Brier score moves only about 12%, because Brier is dominated by irreducible label noise. ECE is biased by the binning choice and sparse bins, so report it with the bin count and, ideally, a reliability diagram; and calibrate on the same distribution you will deploy on, because calibration does not transfer across domains.

$$
\text{Brier}=\frac{1}{n}\sum_i (q_i-y_i)^2,\qquad \text{ECE}=\sum_{b}\frac{|B_b|}{n}\left|\bar q_b-\bar y_b\right|
$$

```python
# Calibration of a yes/no judge: Brier score and expected calibration error (synthetic data)
import random
random.seed(0)
def simulate(n, temp):
    # true P(yes) per item; the judge reports a distorted probability (temp<1 = overconfident)
    out = []
    for _ in range(n):
        p = random.random()
        y = 1 if random.random() < p else 0
        logit = (p / (1 - p + 1e-9)) ** (1 / temp)
        q = logit / (1 + logit)
        out.append((q, y))
    return out
def brier(data):
    return sum((q - y) ** 2 for q, y in data) / len(data)
def ece(data, bins=10):
    tot = 0.0
    for b in range(bins):
        lo, hi = b / bins, (b + 1) / bins
        sel = [(q, y) for q, y in data if lo <= q < hi or (b == bins - 1 and q == 1.0)]
        if sel:
            conf = sum(q for q, _ in sel) / len(sel)
            acc = sum(y for _, y in sel) / len(sel)
            tot += len(sel) / len(data) * abs(conf - acc)
    return tot
for name, t in [("calibrated", 1.0), ("overconfident", 0.4), ("underconfident", 2.5)]:
    d = simulate(20000, t)
    print(f"{name:15s} Brier={brier(d):.4f}  ECE={ece(d):.4f}")
```

### L2 · Separate a stock's news reaction from the market move with a market-model abnormal return

`Domain AI (finance, health)` · now 3.5 → target 4.5 · priority 0.70 · ~15 min

**Why today.** AMD rose 5.86% and Broadcom 5.54% on the day Nvidia's CEO resigned; an event study asks how much of that is news and how much is beta. ([AMD and Broadcom jump about 6% on Nvidia turmoil; William Blair upgrades AMD, CoreWeave falls about 7%](https://www.bloomberg.com/news/articles/2026-11-12/nvidia-turmoil-lifts-amd-broadcom-on-bets-for-business-gains))

Fit r_stock = alpha + beta * r_market + e by OLS on a clean estimation window (here 60 sessions) that ends before the event. On the event day, the abnormal return is the actual return minus alpha + beta * r_market, and dividing by the residual standard deviation gives a t-statistic. For a multi-day window you sum the abnormal returns into a CAR; its variance grows with the number of days, so the t-statistic is divided by sqrt(k). With high-beta chip stocks a market dip makes the expected return negative, so a +5.9% day becomes a +7% surprise. The fitted alpha is noisy over 60 days (here it comes out negative though the true value is positive), confounding events on the same day break the attribution, and fat-tailed returns make |t| > 2 less rare than a normal table suggests.

$$
AR_t = r_t - (\hat\alpha + \hat\beta\, r_{m,t}),\qquad t_{CAR}=\frac{\sum_{t=0}^{k-1} AR_t}{\hat\sigma_e\sqrt{k}}
$$

```python
# Market-model event study: abnormal return and its t-stat (synthetic, illustrative numbers)
import random, statistics as st
random.seed(1)
alpha_true, beta_true, sigma = 0.0003, 1.6, 0.025      # daily; illustrative for a high-beta chip stock
mkt = [random.gauss(0.0005, 0.01) for _ in range(60)]  # 60-session estimation window
stk = [alpha_true + beta_true * m + random.gauss(0, sigma) for m in mkt]
# OLS fit r_i = a + b r_m + e
mx, my = st.mean(mkt), st.mean(stk)
b = sum((x - mx) * (y - my) for x, y in zip(mkt, stk)) / sum((x - mx) ** 2 for x in mkt)
a = my - b * mx
resid = [y - (a + b * x) for x, y in zip(mkt, stk)]
s = (sum(e * e for e in resid) / (len(resid) - 2)) ** 0.5
# Event day: stock +5.9% while the market is -0.4% (illustrative)
r_event, m_event = 0.059, -0.004
ar = r_event - (a + b * m_event)
print(f"alpha={a:.4f} beta={b:.2f} sigma_e={s:.4f}")
print(f"expected return={a + b*m_event:+.4f}  abnormal return={ar:+.4f}  t={ar/s:.2f}")
# 3-day CAR: variance adds, so t scales with sqrt(3)
ars = [ar, -0.010, 0.004]
car = sum(ars)
print(f"CAR[0,2]={car:+.4f}  t={car/(s*3**0.5):.2f}")
```
