### L1 · Put a confidence interval on a benchmark gap before calling it a win

`LLM / agent evaluation` · now 2.5 → target 4.5 · priority 2.00 · ~15 min

**Why today.** Anthropic reports Fable 5.2 at 69.9% on FrontierSWE v2 against 62.3% for Opus 5.5, a 7.6-point gap whose significance depends on how many tasks the benchmark has. ([Anthropic releases Claude Fable 5.2 and Mythos 5.2, cuts Fable price to $8/$40 per million tokens](https://www.anthropic.com/claude-fable-and-mythos-5-2))

A pass rate on n tasks is a binomial estimate with standard error sqrt(p(1-p)/n), so a 7.6-point gap is noise at n=100 and borderline at n=300. Treating the two runs as independent overstates the noise, because both models face the same tasks: the paired (McNemar) view uses only discordant tasks, those one model solves and the other fails, and usually gives a much tighter interval. Run-to-run sampling variance (temperature, agent scaffolding) adds a second noise source that a single run hides, so ask for repeated seeds. The interval also says nothing about contamination or whether the benchmark measures what you care about.

$$
\widehat{\Delta}=\frac{b-c}{n},\qquad \mathrm{SE}(\widehat{\Delta})=\frac{\sqrt{b+c-(b-c)^2/n}}{n}
$$

```python
# Illustrative: is a benchmark gap bigger than sampling noise? (task counts are assumed, not reported)
import math
def gap_ci(p1, p2, n, z=1.96):
    # unpaired two-proportion CI for p1 - p2, both models run on the same n tasks
    se = math.sqrt(p1*(1-p1)/n + p2*(1-p2)/n)
    d = p1 - p2
    return d, d - z*se, d + z*se
def paired_ci(b, c, n, z=1.96):
    # paired: b = tasks only A solves, c = tasks only B solves (McNemar-style)
    d = (b - c) / n
    se = math.sqrt(b + c - (b - c)**2 / n) / n
    return d, d - z*se, d + z*se
for n in (100, 300, 1000):
    d, lo, hi = gap_ci(0.699, 0.623, n)
    print(f"n={n:5d}: gap {d*100:+.1f} pts, 95% CI [{lo*100:+.1f}, {hi*100:+.1f}]  significant={lo>0}")
# Same 300 tasks, but the models agree on most: only 40 vs 17 discordant tasks
d, lo, hi = paired_ci(40, 17, 300)
print(f"paired n=300: gap {d*100:+.1f} pts, 95% CI [{lo*100:+.1f}, {hi*100:+.1f}]")
```

### L2 · Bound an agent kill switch's stop latency when authorizations are cached

`Agent / harness engineering` · now 4.0 → target 5.0 · priority 0.70 · ~10 min

**Why today.** OpenAI's Control Room revokes a job's authorization to stop it, and reports that cached authorizations can delay the halt by up to 35 seconds. ([OpenAI details Control Room, a central kill switch that halts research model workloads within 35 seconds](https://openai.com/index/control-room))

A revocation only takes effect when the worker next consults the authority, so the worst-case stop time is the cache TTL plus propagation delay, not the check interval. Shorter TTLs tighten the bound but multiply load on the authorization service, and if that service is down the system must choose fail-closed (stop everything) or fail-open (keep running). OpenAI's description says it fails closed. Push-based revocation can beat the TTL bound but needs a reliable channel, so production designs usually combine a push with a TTL as the backstop. The simulation shows mean latency near half the TTL while the worst case sits at the bound, and the bound is what matters for safety.

$$
T_{stop}^{\max}=T_{prop}+\max(T_{TTL},\,T_{check})
$$

```python
# Illustrative: worst-case stop latency with cached authorizations (numbers are assumed)
import random
def stop_latency(ttl, check_every, propagate, trials=100_000, seed=0):
    rng = random.Random(seed)
    worst = total = 0.0
    for _ in range(trials):
        cache_age = rng.uniform(0, ttl)          # how old the cached 'allowed' verdict is at revoke time
        expire = ttl - cache_age                 # time until the cache must re-check
        next_check = rng.uniform(0, check_every) # engine checks cache before each generation step
        lat = propagate + max(expire, next_check)
        worst = max(worst, lat); total += lat
    return total / trials, worst
for ttl in (5, 15, 30):
    mean, worst = stop_latency(ttl, check_every=1.0, propagate=2.0)
    print(f"cache TTL {ttl:2d}s: mean stop {mean:5.1f}s, worst {worst:5.1f}s (bound = TTL + propagate = {ttl+2}s)")
```
